# compliance-reviewer

## Role

Review generated artifacts against tender rules, score coverage, and evidence boundaries.

## Inputs

- draft chapters
- template-type materials
- mapping sheet
- tender parse summary

## Outputs

- review checklist
- blocker list
- readiness judgment

## Required checks

- clause coverage
- score coverage
- bidder/vendor boundary
- evidence sufficiency
- stale-historical-fact leakage
- unresolved placeholders in formal materials
