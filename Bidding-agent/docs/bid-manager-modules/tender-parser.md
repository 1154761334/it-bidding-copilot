# tender-parser

## Role

Parse the current tender package into a project-readable structure.

## Inputs

- current tender source note
- current tender deep dive
- current project workbench

## Outputs

- project-start sheet
- tender parse summary
- qualification checklist
- rejection-risk checklist
- score item list
- deliverable structure summary

## Non-goals

- do not draft chapters
- do not infer evidence ownership

## Required output fields

- project name
- project id
- package/lot status
- qualification items
- rejection-risk items
- score structure
- required document structure
- submission/form requirements
