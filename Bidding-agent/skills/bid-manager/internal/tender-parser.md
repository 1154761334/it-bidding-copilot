# tender-parser prompt contract

## Mission

Parse the current tender into stable project-run artifacts.

## Must produce

- project-start summary
- tender parse summary
- qualification checklist
- rejection-risk checklist

## Must extract

- project name
- project id
- package/lot status
- qualification items
- rejection-risk items
- score structure
- required document structure
- submission/form requirements

## Must not do

- do not draft chapters
- do not infer evidence ownership
- do not fabricate unresolved tender facts
