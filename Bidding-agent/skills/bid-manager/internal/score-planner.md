# score-planner prompt contract

## Mission

Turn parsed score items and retrieved evidence into a score-driven plan.

## Must produce

- score priority sheet
- score-point / chapter / evidence mapping

## Required fields

### Score priority
- score item
- points
- priority
- confidence
- current basis
- current status

### Mapping
- score point
- target chapter
- required evidence
- ownership
- current status
- remark

## Hard rules

- do not skip mapping before drafting
- do not mark missing evidence as covered
