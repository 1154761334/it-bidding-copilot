# 脚本目录说明

当前 `scripts/` 按职责分为三类：

- `ops/`: 初始化、迁移、盘点、运维辅助
- `seed/`: 演示数据与结构化种子
- `verify/`: 真实链路联调与验证

使用原则：

1. 一次性实验脚本不要再直接丢在 `scripts/` 根目录
2. 需要长期保留的脚本必须进入上述三类之一
3. 新增验证脚本优先放到 `scripts/verify/`
4. 新增演示数据脚本优先放到 `scripts/seed/`

常用运维脚本补充：

- `scripts/ops/check_runtime_assets.py`

用途：

- 检查当前机器是否具备关键运行时资产
- 明确 `models/`、样例文档、模板和 `.env` 是否存在
- 辅助判断“当前仓库 clone 下来后为什么不能直接完整复现服务器环境”
