# 主流程任务清单

本文档把当前项目收敛成唯一产品主线，并作为后续连续开发的执行清单。

## 1. 目标主线

1. 企业资料建库
2. 新建投标项目
3. 起草前素材确认
4. 在线编标工作台
5. 审标与导出

## 2. 任务清单

### Phase 1 企业资料建库

- `done` 企业资产统一沉淀：上传、导入、浏览、编辑、删除、批量删除
- `done` 商务技术文件预提资质：规则切块 + LLM 标准化 + 后端校验后入库
- `done` 企业资产中心新增“企业建库确认”检查区
- `done` 企业资产中心新增“本轮新入库资产待确认”批次摘要
- `in_progress` 继续打磨企业资产数据治理，减少误提、重复和错分类
- `planned` 强化“本轮新入库资产待确认”视图，补批次级确认与回退操作

### Phase 2 新建投标项目

- `done` 采购文件上传与异步解析
- `done` `analysis-check` 质量校验
- `done` `/rfp` 页面增加项目信息与需求修正后确认保存
- `done` 偏离矩阵页面增加“分析未确认需先返回建档”的步骤提示
- `planned` 将评分表、资格要求、技术要求拆成更清晰的确认界面
- `planned` 明确“确认后正式建档”与“未确认仅预览”的状态区分

### Phase 3 起草前素材确认

- `done` 编标大厅新增“项目素材包”确认区
- `done` 支持从企业资产库勾选证书、案例、人员
- `done` 支持上传项目专属方案材料
- `done` 支持 AI 推荐素材并允许人工调整
- `done` 素材包确认前拦截章节生成与整项目自动续写
- `planned` 为素材包补推荐理由、证据预览和更细的人工确认操作

### Phase 4 在线编标工作台

- `in_progress` 以 Markdown 编辑工作区替换当前中部展示区，现已支持在线编辑
- `in_progress` 支持章节在线编辑、保存和版本递增
- `planned` 支持选中内容后让 AI 改写
- `planned` 支持整章重写、补强、压缩、对齐评分点
- `partial` 右侧已显示引用证据与建议，仍需继续细化 AI 操作面板

### Phase 5 审标与导出

- `done` 红队审标与导出前检查
- `done` 不合格项目导出拦截
- `in_progress` 导出前检查显示采购母版、图片证据和被拦截章节详情
- `planned` 审标意见一键回到待修章节
- `planned` 模板保样式导出继续增强
- `planned` 审标后自动修复闭环

## 3. 当前执行顺序

1. 先完成 Phase 1 与 Phase 2 的确认链路
2. 再落 Phase 3 的项目素材包
3. 之后重构 Phase 4 为真正的在线编标工作台
4. 最后继续收 Phase 5 的成品导出质量
