# 开发日志目录

本目录用于记录每一轮有效开发，服务于多 AI 协作、状态追溯和问题回看。

## 记录规则

- 只在关键轮次新增日志，不要求每次小改动都写
- 日常开发优先使用 GitHub commit / PR 留痕
- 日志文件命名：`YYYY-MM-DD-agent-name.md`
- 同一天可以有多篇，例如：
- `2026-04-09-codex.md`
- `2026-04-09-gemini-flash.md`

## 建议模板

可直接参考：

- [TEMPLATE.md](/root/it-bidding-copilot/docs/development_logs/TEMPLATE.md)

## 建议阅读顺序

1. 先看最近一篇
2. 再看最近 3 篇，确认本轮与上轮之间是否存在返工或方向变化
3. 如有重大架构调整，再回看对应日期的 `docs/current_status.md`
