# Contributing to IT Bidding Copilot

We welcome contributions to the **IT Bidding Copilot** project! This document provides guidelines for contributors.

## How to Contribute

### 1. Reporting Bugs
- Use the **Issue Tracker** to report bugs.
- Include details about your environment (Python version, OS) and steps to reproduce the issue.

### 2. Suggesting Features
- Open an **Issue** to discuss new features.
- Provide a clear description of the feature's goal and potential implementation.

### 3. Submitting Pull Requests
- Fork the repository and create a new branch for your changes.
- Ensure your code follows the existing style (PEP 8 for Python).
- Write clear commit messages.
- If your change affects the UI or logic, update the documentation (`README.md` or `docs/`).

## Local Development Setup

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Set up your `.env` file with necessary API keys.
4. Run tests: `pytest` (if available).

## Code of Conduct

Please be respectful and professional in your interactions within this project.
