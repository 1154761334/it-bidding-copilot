# 浙江省财务开发有限责任公司私有云建设项目招标文件

## 第一章 招标公告

浙江省财务开发有限责任公司（以下简称“采购人”）就“私有云建设项目”进行公开招标，欢迎合格的投标人前来投标。

**1. 项目名称**：浙江省财务开发有限责任公司私有云建设项目
**2. 采购预算**：人民币 3,500,000 元
**3. 投标截止时间**：2026年6月10日 09:30

## 第二章 投标人资格要求（▲实质性要求）

▲1. 投标人必须具有独立承担民事责任的能力。
▲2. 投标人必须提供有效的营业执照副本复印件加盖公章。
▲3. 投标人需提供所投核心云平台产品原厂授权书及售后服务承诺函。
▲4. 投标人需具备 ISO9001 质量管理体系认证证书。
▲5. 投标人需具备至少一个近三年（2023年1月1日至今）金额不少于200万元的类似私有云建设项目成功案例。

## 第三章 采购需求及技术指标

本项目旨在建设一套高可用、安全可靠的私有云平台，满足公司内部各项业务系统的云化部署与弹性扩展需求。

### 3.1 核心云平台要求
△1. 平台需支持计算、存储、网络等资源的统一管理和编排。
△2. 计算虚拟化需支持平滑升级，且不中断业务虚拟机。
3. 提供统一的图形化自服务门户。

### 3.2 存储系统要求
△1. 采用分布式存储架构，需提供至少 50TB 的可用块存储容量。
2. 支持快照、克隆、精简配置等高级功能。

### 3.3 安全隔离要求
△1. 平台自带虚拟防火墙功能，支持微隔离。
▲2. 满足等保三级相关技术要求。

## 第四章 评标办法

本项目采用综合评分法，总分100分。

**1. 价格分 (30分)**
以满足招标文件要求且投标价格最低的投标报价为评标基准价。

**2. 商务资信分 (20分)**
- 体系认证（5分）：具备 ISO27001 信息安全管理体系认证得5分，没有不得分。
- 类似案例（15分）：在满足资格要求的一个案例基础上，每增加一个类似案例得5分，最高得15分。

**3. 技术方案分 (50分)**
- 整体架构设计合理性（15分）：视方案的先进性、高可用性酌情打分。
- 技术指标响应程度（25分）：带“△”指标每负偏离一项扣2分，一般指标每负偏离一项扣1分。
- 项目实施及售后团队（10分）：项目经理具有 PMP 及高级软考证书得5分。
